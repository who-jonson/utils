# Security Policy

## Supported Versions

Security fixes are released for the latest published version of each package (`@whoj/utils`, `@whoj/utils-core`, `@whoj/utils-php`, `@whoj/utils-vue`, `@whoj/utils-types`). Please upgrade to the latest version before reporting.

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report them privately using GitHub's private vulnerability reporting:
[Report a vulnerability](https://github.com/who-jonson/utils/security/advisories/new) (repository `who-jonson/utils` → Security → Report a vulnerability).

Please include the affected package and version, a description of the issue, and a minimal reproduction if possible. We will acknowledge the report, work on a fix, and publish a security advisory once a patched version is available.
